# 🐾 دستیار دامپزشکی هوشمند - Smart Vet

یک پلتفرم پیشرفته مبتنی بر هوش مصنوعی برای تشخیص بیماری‌های حیوانات و ارائه توصیه‌های دارویی.

## ✨ امکانات

- 🔍 **تشخیص هوشمند بیماری‌ها** با دقت 94%
- 💊 **توصیه دارویی** بر اساس تشخیص
- 📋 **مدیریت پرونده حیوانات**
- 👤 **پنل کاربری** برای صاحبان حیوانات
- 🌐 **پشتیبانی چندزبانه** (فارسی/انگلیسی)
- 💰 **سیستم پرداخت و کیف پول**

## 🛠 تکنولوژی‌ها

- **فرانت‌اند:** React 18 + TypeScript + Vite
- **استایل:** Tailwind CSS + Framer Motion
- **دیتابیس:** JSON Server (محلی)
- **آیکون‌ها:** React Icons
